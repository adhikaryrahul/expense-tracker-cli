# Expense Tracker CLI

A command-line expense tracker built in Python. Expenses are stored in a local JSON file.

## Features
- Add and view expenses
- Calculate total spending
- See spending by category
- Data saved to a JSON file between runs

## Requirements
- Python 3.x (no external libraries)

## How to run
```
python main.py
```

